# Steamのシステム要件欄に、存在しないGPUが書かれている

Steamのゲームページには「最低動作環境」と「推奨動作環境」という2つのスペック欄がある。購入を検討するユーザーが最初に参照する数値であり、開発者がゲームの動作保証範囲を宣言する場でもある。今回、この欄に異様な記述を持つゲームを3本記録した。存在しないGPU、MBとGBの混同、2003年製ハードウェアを推奨するゲーム——それぞれがSteamというプラットフォームの別の側面を映している。

## Waves of Death（#858740）：推奨スペックに存在しないGPUが書かれている

¥1010、レビュー11件、2020年3月リリース。

最低動作環境のCPU欄には「17」と書かれている。Intel Core i7の誤記と思われるが、ストアページには「17」のままになっている。これだけであれば単純な記入ミスだが、推奨環境を見ると状況が変わる。

推奨GPUは「NVIDIA GTX 2048 TI」。このGPUは存在しない。

NVIDIAの20シリーズの最上位は「RTX 2080 Ti」だが、「GTX 2048 TI」という型番はNVIDIAの製品ラインナップのどこにも登場しない。GTXとRTXのブランドが混在し、「2048」という数字はVRAM容量（MiB単位）由来の可能性もあるが、開発者に確認する手段はない。

最低要件のGPUはNVIDIA GTX 1080 Ti（実在する。2017年発売の高性能モデル、当時の実売価格は約80,000円）。その上位として推奨される「GTX 2048 TI」は、5年間誰にも訂正されないまま掲載され続けている。

RAM要件は最低8GB、推奨16GB。こちらは整合している。解像度に関しては推奨設定の注記として「1366×768でシェーディングをローに設定することを推奨」と添えられており、存在しないGPUの推奨とは対照的に、この一行は異様に具体的で実際的である。

## Wat A Life（#1221430）：RAMの単位がMBになっている

¥235、レビュー3件、2020年3月リリース。

最低動作環境：RAM **8 MB**
推奨動作環境：RAM **16 MB**

2020年代に販売されているゲームのRAM要件として、8 MBという数値は現実的ではない。Steamクライアント自体でもこれほど少量のRAMでは起動しない。GB（ギガバイト）をMB（メガバイト）と誤記したものと考えられる——最低8GB、推奨16GBと読めば、他のスペックとは整合する。

GPU要件は最低GeForce GTX 770（2013年）、推奨GTX 970（2014年）。CPUも最低Intel Core i5またはAMD FX 4300、推奨i7またはFX 9590と記載されており、この部分は2020年のゲームとして特に問題のない記述になっている。RAM欄だけがGBをMBと書いている。

ゲームの内容は「ゲームの中でゲームを作る、ゲーム内のゲームをプレイする、テイクアウトを注文する、オンラインショッピングをする」という一文で説明されている。夢を叶えるためにお金を稼ぐことが目的とされており、その夢がどのようなものかは説明文から読み取れない。16 MB（あるいは16 GB）のRAMで動作するはずのライフシミュレーションである。

## UFO穿越（#1179690）：推奨スペックがWindows XPを指定している

¥350、レビュー1件、2020年3月リリース。

最低動作環境のOSは「Windows® 7 32/64位 / Vista 32/64 / XP」。そして推奨動作環境のOS欄を見ると、同じ記述がそのまま繰り返されている。最低でも推奨でも、このゲームの対応OSはWindows XP以上とされている。

最低要件のグラフィックカードは「128 MB，Shader model 2.0，ATI 9600，NVidia 6600 或更高」。Shader Model 2.0はDirectX 9の時代で、ATI Radeon 9600は2003年に発売されたGPUである。RAM最低要件は1 GB。

推奨環境のGPUはNVIDIA GeForce GTX 660（2012年）。最低要件のATI 9600（2003年）から推奨要件のGTX 660（2012年）にかけて、9年分のハードウェア世代が存在する。

なお推奨ストレージ欄には「10 MB の空き容量」と記載されている。最低要件のストレージは5 GBであるため、推奨が10 MBというのは順序が逆転している。推奨が最低を大幅に下回るストレージ要件として、このゲームのスペック欄の性質を端的に表している。

タイトルの「UFO穿越」は中国語で「UFO横断」あるいは「UFO貫通」の意味を持ち、説明文は英語で「宇宙人が地球を攻撃する、人類を狩る、世界を救う意志はあるか」と書かれている。

## 横断考察

3本のゲームはいずれも2020年3月前後のリリースで、レビュー数の合計は15件、価格は¥235〜¥1010の範囲に収まっている。

スペック欄の異常という点は共通しているが、その種類はそれぞれ異なる。Waves of Deathには製造されたことのないGPUのモデル番号が書かれており、Wat A LifeはGBをMBと取り違え、UFO穿越は現行のWindowsよりも20年前のOSを今も「推奨」と掲げ続けている。

Steamのシステム要件欄は、開発者が自己申告で記入するフィールドである。Valveによる数値の検証や、型番の実在確認は行われない。このため、存在しない型番も、単位の誤りも、市場から撤退して久しいOSの指定も、指摘されない限りそのままページに残り続ける。

購入前にシステム要件を確認するという行為に、どれほどの信頼性を置くことができるか。これらのページを並べると、その問いの輪郭が少しだけはっきりする。
